# Negative and falsification controls

| Claim | Controls that must fire |
| --- | --- |
| 1 | Noncommuting subspaces; independent unit test; exact component nonnegativity and sum |
| 2 | Equal spectra, reversed order, learnability boundary, sign flip, corrupted student rate; independent boundary grid |
| 3 | Zero signal, unstable step, nonexpressive model, non-low-dimensional embedding, high noise that destroys the witness |
| 4 | `alpha_S=1` removes stopping mismatch, oracle `R_S=0` validates the PGR substitution, nonzero `R_S` breaks it, corrected `n` exponent differs |
| 5 | Fixed shuffled pseudolabels must be worse than best W2S with positive paired CI; `+0.01` corrupted summaries must be rejected |

The cumulative gate requires every control and independent checker to pass.
A control that does not fire makes the fixed command exit nonzero.
