# What Makes a Strong Model? A Unified Spectral Analysis of Knowledge Transfer

Clean-room reproduction for OpenReview `ykWN4LG9vE` / arXiv `2606.01292`.

The package will verify the three scored claims in the paper's linear-SGD
setting: the teacher-to-student geometric decomposition, spectral-horizon
expansion in knowledge distillation, and spectral denoising in weak-to-strong
transfer. The accepted source archive has no author code, so this package does
not claim source-code parity.

The primary synthetic KD protocol will use the paper's stated `d=100`,
`N=2,000`, `n=500,000` two-phase, single-sample SGD setup.  Real-world
backbone experiments are outside this clean-room linear-model scope and will
not be substituted with proxy evidence.
